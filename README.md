# 🌿 Permaculteur

> Application de suivi des plantes (hydratation · nutriments · croissance)
> **Projet fil rouge de la formation IA pour designers**

---

## Vue d'ensemble

Permaculteur est une app web mobile-first pour aider les utilisateurs à prendre soin de leurs plantes : rappels d'arrosage, suivi des nutriments, journal de croissance, diagnostic de symptômes.

Ce projet sert de **support pédagogique** pour la formation "IA pour designers" — il intègre toute la chaîne research → PM → design → code → documentation.
